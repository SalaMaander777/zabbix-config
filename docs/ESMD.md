# R&S ESMD: протокол опроса

## Что подтверждено источниками
- **Управление по LAN, SCPI.** Брошюра ESMD (R&S, v1001, 2019-07, [PDF](https://scdn.rohde-schwarz.com/ur/pws/dl_downloads/dl_common_library/dl_brochures_and_datasheets/pdf_1/ESMD_bro_en_5213-9863-12_v1001.pdf), с. 27): две LAN-карты 1 Гбит/с для удалённого управления и вывода результатов; «open interface description for remote control commands (in line with the SCPI standard)». Номер порта в брошюре не указан.
- **Описание команд ESMD в открытом доступе не найдено.** Страница ESMD на сайте R&S: прибор снят с производства (преемник R&S ESME); в Download Center для ESMD только брошюра и две статьи про TDOA, руководств (0), ПО (0). Руководство и ESMD-Control, возможно, за регистрацией Knowledge+ или выдаются по запросу в R&S/у поставщика.

## Что известно по родственному прибору (НЕ ESMD)
Руководство R&S EB500 (Operating Manual 4072.8426.02 v08, [копия](https://rigpix.com/rohdeschwarz/eb500_manual.pdf), гл. 4 «Remote Control via LAN»): SCPI 1993.0 по сырому TCP-сокету, **порт по умолчанию 5555**, проверка соединения командой `*idn?` (в Telnet), команда завершается переводом строки (LF), очередь ошибок `SYSTem:ERRor?`, порт настраивается командой `SYSTem:COMMunicate:LAN:PORT`.
Вывод: порт 5555 из памяти заказчика согласуется с семейством приборов R&S для радиомониторинга, но для ESMD это **аналогия, а не подтверждение**. Порты 5025/5125/4880/111/2525 (общие для R&S) для ESMD тоже не подтверждены.

## Как подтвердить на приборе (с ноутбука в одной сети)
1. `ping <IP>`; `Test-NetConnection <IP> -Port 5555` (PowerShell) - порт открыт?
2. Если нет - сканировать порты (nmap) и свериться с настройкой LAN в меню прибора/ESMD-Control.
3. Открыть сокет (PuTTY raw/Telnet), послать `*IDN?` + Enter: ожидается строка вида `ROHDE&SCHWARZ,ESMD,...`.
4. Проверить `SYSTem:ERRor?`. Если ответы есть - включить два выключенных элемента данных в шаблоне.
5. Уточнить, не ограничено ли число одновременных соединений: опрос раз в 5 минут короткими сессиями, ESMD-Control/ARGUS на приборе не должны отваливаться.
