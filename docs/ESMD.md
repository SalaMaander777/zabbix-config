# R&S ESMD: протокол опроса
Статус: **не подтверждён**. Порт 5555 — со слов заказчика. Руководство в открытом доступе в этой сессии не найдено и не прочитано; часть документов R&S (Knowledge+) требует регистрации.
План: найти руководство и описание удалённого управления ESMD (ESMD-Control), подтвердить порт/протокол, затем на приборе проверить `zabbix/externalscripts/esmd_check.py tcp <IP> <порт>`. Режим `raw` принимает команду аргументом, значений по умолчанию нет. Порты R&S из ТЗ (5025/5125, 4880, 111, 2525) — только справка.
Шаблон `templates/esmd_icmp_tcp.yaml`: ICMP, время ответа, TCP-порт `{$ESMD.PORT}`.
