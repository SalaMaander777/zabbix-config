# Карты: варианты (решение до реализации)
| Вариант | Плюсы | Минусы |
|---|---|---|
| A. Карты Zabbix (схема связей) с локальной картинкой-подложкой | встроено, офлайн, статусы | не география, нет экспорта в Excel |
| B. Geomap виджет + локальный сервер тайлов (например, контейнер tileserver с MBTiles OSM Москвы и области) | реальная карта в Zabbix | нужны заранее подготовленные тайлы (размер, лицензия OSM), координаты в инвентаре хостов |
| C. Отдельный лёгкий веб-слой (Leaflet + локальные тайлы, данные из API Zabbix, выгрузка в xlsx) | карта и Excel в одном месте | своя разработка и поддержка |
Предварительная рекомендация: A для схем связей + C для карты Москвы/области и Excel; B как вариант, если Excel достаточно получать отдельным отчётом. Решает заказчик.
