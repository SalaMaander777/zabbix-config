# Машины для установки

## Тестовая: Windows 11 Pro для рабочих станций, 26H1 (сборка 28000)
Подходит для Docker Desktop (требование: Windows 11 23H2, сборка 22631 или новее; WSL 2.1.5+; 8 ГБ RAM; виртуализация в BIOS/UEFI).
Порядок: `scripts\install-docker-win11.ps1` → перезагрузка → запуск Docker Desktop → `scripts\load-and-start.ps1`.

## Целевая: Windows 10 Корпоративная LTSC (по снимку: © 2018, классическое окно «Система»), Pentium G3430 (2 ядра), 10 ГБ RAM, x64
Судя по снимку это LTSC 2019 (версия 1809, сборка 17763). **Точную сборку подтвердить командой `winver`.**
Если так, то:
- **WSL2 недоступен**: нужна версия 1903, сборка 18362.1049 или новее (Microsoft Learn: «Builds lower than 18362 do not support WSL 2»).
- **Docker Desktop не поддерживается**: и для WSL2, и для Hyper-V бэкенда требуется Windows 10 22H2 (сборка 19045). Даже LTSC 2021 (сборка 19044) ниже этого требования.

Варианты (решение заказчика, отступление от ТЗ):
| Вариант | Суть | Плюсы | Минусы |
|---|---|---|---|
| A. Виртуальная машина Linux в Hyper-V | Hyper-V входит в Windows 10 Enterprise; в ВМ ставится Linux + Docker Engine, стек тот же | Windows не трогаем; ВМ стартует при загрузке без входа пользователя (закрывает вопрос автозапуска); нет вопроса лицензии Docker Desktop | нужен офлайн-образ Linux и пакеты Docker; надо проверить, что CPU поддерживает SLAT (`systeminfo`, раздел «Требования Hyper-V») |
| B. Обновить ОС до Windows 10 22H2 / Windows 11 | затем Docker Desktop по скрипту для Win11 | совпадает с исходным ТЗ | переустановка/обновление ОС на главном ПК; G3430 не проходит требования Windows 11; лицензия Docker Desktop |
| C. Разместить сервер на другой машине (например, на Windows 11 с первого снимка) | — | ничего не менять | другая машина должна работать круглосуточно |
Предварительная рекомендация: A. Не реализовано до решения заказчика.

Ресурсы (2 ядра, 10 ГБ RAM) для ~100 устройств достаточны; при варианте A выделить ВМ 2 vCPU, 4-6 ГБ RAM, диск 60 ГБ.
Windows не активирована (по снимку) - на работу стека не влияет, вопрос лицензирования на стороне заказчика.
