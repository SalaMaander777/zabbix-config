# Решения, отступления от ТЗ, открытые вопросы

## Отступления от ТЗ (требуют согласования)
1. **Данные PostgreSQL в именованном томе Docker, а не в папке хоста.** Bind-mount папки NTFS в WSL2 ломает права каталога данных postgres. Бэкапы (pg_dump) и конфиги лежат в папках хоста (`backups/`, `zabbix/`, `templates/`).
2. **Версия Zabbix: 7.0.32** (тег `alpine-7.0.32` для amd64 существует на Docker Hub на 2026-11-10, это последний 7.0.x в списке тегов на тот момент). Закреплено в `.env`; обновление только по решению заказчика.
3. **Образ сервера собственный** (`server/Dockerfile`): базовый alpine-образ не содержит python3, добавлен `apk add python3`. Выбран вариант «расширенный образ», а не отдельный контейнер, т.к. внешние скрипты Zabbix вызываются самим сервером.

## Открытые вопросы (требует проверки)
| Вопрос | Кто | Влияние |
|---|---|---|
| Лицензия Docker Desktop (организация >250 человек или >$10 млн выручки платная); запасной вариант Docker Engine в WSL2 | заказчик/юристы | выбор способа установки |
| Автозапуск без входа пользователя: Docker Desktop стартует при входе в систему. Варианты: автологин на главном ПК, либо Docker Engine в WSL2 + задача планировщика при загрузке | заказчик | критерий «после перезагрузки сам» |
| Версия SNMP (v2c/v3), модели и ПО Cisco/Infinet | заказчик | v2c и v3 поддерживаются, макросы в шаблонах |
| Протокол, команды ESMD (и проверка EB500) | проверка на приборе | порт 5555 и ответ на `*IDN?` подтверждены заказчиком; SCPI по LAN подтверждён брошюрой, команды ESMD не подтверждены; руководство ESMD не в открытом доступе, см. `docs/ESMD.md` |
| NTP в целевой сети | заказчик | см. `docs/RUNBOOK.md`, раздел «Время» |
| Версия Windows 7 на ПК, допустимость агента; совместимая версия агента Win7 | заказчик + тест | агент для Win7 не выбран: версию подобрать и проверить на тестовой машине |
| Браузеры на рабочих местах Win7 | заказчик | совместимость интерфейса 7.0 не проверена |
| Срок хранения трендов (сейчас 365 дней) | заказчик | размер БД |
| Структура групп хостов (в `post_setup.py` черновик: Регион/…, Роль/…) | заказчик | — |
| Вариант карты (см. `docs/MAPS.md`) | заказчик | задача 7 не реализована |

## Правило
OID, SCPI-команды, порты не выдумываются. В шаблоне Infinet только стандартные OID MIB-II (sysUpTime, sysDescr); остальное добавляется из MIB Infinet.
