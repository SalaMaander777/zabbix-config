# Решения, отступления от ТЗ, открытые вопросы

## Решения и отступления от ТЗ
1. **Сервер — в виртуальной машине Linux под Hyper-V (путь A), а не в Docker Desktop.** Целевая Windows 10 LTSC 2019 (сборка 17763) не поддерживает WSL2 (нужна 18362+) и Docker Desktop (нужна 19045+). ВМ стартует при загрузке Windows без входа пользователя (закрывает требование автозапуска) и снимает вопрос лицензии Docker Desktop. Запасные варианты: A2 — та же ВМ в VirtualBox; B — Docker Desktop на другом ПК с Windows 11. Подробно: `WINDOWS-TARGET.md`, `DEPLOY.md`.
2. **Данные PostgreSQL в именованном томе Docker**, а не в папке хоста (bind-mount NTFS ломает права postgres). Бэкапы и конфигурация — в папках (`backups/`, `zabbix/`, `templates/`).
3. **Версия Zabbix 7.0.32** (последний 7.0.x на 2026-11-10), закреплена в `.env`; обновление только по решению заказчика.
4. **Собственный образ сервера** (`server/Dockerfile`): базовый образ без python3, добавлен для внешнего скрипта опроса ESMD/EB500.
5. **Карта — отдельный сервис `zabbix-map`** (Leaflet + локальные тайлы OpenStreetMap Москвы и области, выгрузка в Excel), порт 8081. Схемы связей — штатные карты Zabbix. `MAPS.md`.
6. **Оповещения только в веб-интерфейсе** (решение заказчика): без почты, мессенджеров и звука.
7. **Хранение:** история 90 дней, тренды 365 дней (тренды — согласовать).

## Открытые вопросы
| Вопрос | Кто | Влияние |
|---|---|---|
| Включена ли виртуализация в BIOS главного ПК, есть ли пароль на BIOS | заказчик, `precheck.ps1` | без неё сервер на этом ПК невозможен |
| Версия SNMP и учётные данные Cisco (1921/K9, 2901/K9) и Infinet | заказчик | инструкция SNMPv3 — `CISCO.md` |
| OID Infinet на реальном R5000 (шаблон по MIB WANFleX/MINT, проверен на имитаторе) | snmpwalk на устройстве | `INFINET.md` |
| Дословные ответы ESMD на SCPI-запросы (порт 5555 и ответ на `*IDN?` подтверждены) | проверка на приборе | `ESMD.md` |
| NTP в целевой сети | заказчик | без NTP время ВМ берётся у Windows (Hyper-V) или идёт само (VirtualBox) |
| Агент на Windows 7 (классический 7.0 в комплекте) и браузер на Win7 (Firefox ESR 115 в комплекте) | тест на месте | — |
| Пороги Infinet (`{$INFINET.*}`) и структура групп (`Регион/…`, `Роль/…`) | заказчик | значения предварительные |
| Лицензия Docker Desktop (только для пути B) | заказчик | — |

## Правило
OID, SCPI-команды и порты не выдумываются: всё в шаблонах взято из MIB, руководств или подтверждено заказчиком; неподтверждённое помечено.
